## Quick Block

### ipset
ipset create country_block hash:net
while read cidr; do ipset add country_block $cidr; done < CN_cidrs.txt
iptables -I INPUT -m set --match-set country_block src -j DROP

### iptables direct
while read cidr; do iptables -A INPUT -s $cidr -j DROP; done < CN_cidrs.txt
