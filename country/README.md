## Quick Block

### ipset
ipset create blacklist_country hash:net
while read cidr; do ipset add blacklist_country $cidr; done < country/CN_cidrs.txt
iptables -I INPUT -m set --match-set blacklist_country src -j DROP

### iptables
while read cidr; do iptables -A INPUT -s $cidr -j DROP; done < country/CN_cidrs.txt
