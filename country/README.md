# BLACKSHIELD - Country IP Ranges

Country-specific CIDR blocks extracted from multiple authoritative sources including RIR delegation data, IP2Location, MaxMind, ipdeny, and country-ip-blocks.

## Sources
- RIR data (APNIC, ARIN, RIPE, AFRINIC, LACNIC)
- IP2Location Lite database
- MaxMind GeoLite2
- ipdeny.com aggregated zones
- herrbischoff country-ip-blocks
- FireHOL IPsets
